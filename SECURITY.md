| Version | Supported          |

## Reporting a Vulnerability

Security is a foundational tenet of Anti-Slop Engineering. If you discover a vulnerability or security bypass within this repository or the heuristic diff guard, please report it responsibly.

### How to report

Please do not open a public issue. Instead, report security concerns directly to the project author:

- **Email:** `mamdouhfces1997@gmail.com`
- **Subject:** `[Security] Anti-Slop Engineering Vulnerability Report`

Please include:
1. Description of the issue or security bypass pattern.
2. Steps to reproduce or proof-of-concept diff.
3. Potential impact or risk evaluation.

You will receive an acknowledgment within 48 hours, followed by an assessment and patch timeline.
