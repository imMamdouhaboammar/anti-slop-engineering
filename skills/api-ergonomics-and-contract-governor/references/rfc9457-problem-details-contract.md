# RFC 9457 Problem Details Contract

> All HTTP APIs, SDK exceptions, and CLI errors must adhere to the IETF RFC 9457 (superseding RFC 7807) Problem Details for HTTP APIs standard.

## RFC 9457 Core Schema

| Field | Type | Description |
| --- | --- | --- |
| `type` | URI string | Absolute or relative URI reference identifying the problem type |
| `title` | string | Short, human-readable summary of the problem type |
| `status` | integer | HTTP status code generated by the origin server |
| `detail` | string | Human-readable explanation specific to this occurrence |
| `instance` | URI string | URI reference identifying the specific occurrence of the problem |

---

## Machine-Actionable Extension Fields

In accordance with Section 3.2 of RFC 9457 ("Extension Members"), the following fields are mandatory for high-DX SDKs and CLIs:

| Extension Field | Type | Description |
| --- | --- | --- |
| `code` | string | Deterministic, snake_case machine error token (e.g. `rate_limit_exceeded`) |
| `invalid_params` | array | List of `{ name: string, reason: string, code: string }` for validation failures |
| `suggested_action` | string | Machine or human instruction detailing how to resolve the failure |
| `doc_url` | URI string | Direct URL to developer documentation explaining the error and fix |
| `retryable` | boolean | Boolean indicating whether retrying after backoff is safe and meaningful |

---

## TypeScript Error Class Implementation

```typescript
export interface InvalidParam {
  readonly name: string;
  readonly reason: string;
  readonly code: string;
}

export interface ProblemDetailsPayload {
  readonly type: string;
  readonly title: string;
  readonly status: number;
  readonly detail: string;
  readonly instance: string;
  readonly code: string;
  readonly retryable: boolean;
  readonly invalid_params?: readonly InvalidParam[];
  readonly suggested_action?: string;
  readonly doc_url?: string;
}

export class ProblemDetailsError extends Error {
  readonly type: string;
  readonly title: string;
  readonly status: number;
  readonly detail: string;
  readonly instance: string;
  readonly code: string;
  readonly retryable: boolean;
  readonly invalid_params: readonly InvalidParam[];
  readonly suggested_action?: string;
  readonly doc_url?: string;

  constructor(payload: ProblemDetailsPayload) {
    super(`[${payload.code}] ${payload.title}: ${payload.detail}`);
    this.name = "ProblemDetailsError";
    this.type = payload.type;
    this.title = payload.title;
    this.status = payload.status;
    this.detail = payload.detail;
    this.instance = payload.instance;
    this.code = payload.code;
    this.retryable = payload.retryable;
    this.invalid_params = payload.invalid_params ?? [];
    this.suggested_action = payload.suggested_action;
    this.doc_url = payload.doc_url;

    if (Error.captureStackTrace) {
      Error.captureStackTrace(this, ProblemDetailsError);
    }
  }

  toJSON(): ProblemDetailsPayload {
    return {
      type: this.type,
      title: this.title,
      status: this.status,
      detail: this.detail,
      instance: this.instance,
      code: this.code,
      retryable: this.retryable,
      invalid_params: this.invalid_params,
      suggested_action: this.suggested_action,
      doc_url: this.doc_url,
    };
  }
}
```
