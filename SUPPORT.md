# Support

Use the repository issue tracker at https://github.com/imMamdouhaboammar/anti-slop-engineering/issues for reproducible defects, false positives, triage guard adjustments, documentation corrections, and compatibility requests.

Include the version, command invocation, environment details, and minimal reproduction. Do not include credentials, secrets, or proprietary private code in public issues.

## Security Vulnerabilities

To report a suspected security vulnerability or sensitive defect, see [SECURITY.md](./SECURITY.md) for private reporting steps.
